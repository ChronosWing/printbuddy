# PrintBuddy v0.2.5.3-u1.2

This release adds optional Spoolman location synchronization and fixes Snapmaker U1 chamber-light state initialization. It builds on the [original PrintBuddy project](https://github.com/vmhomelab/Printbuddy) and the fork's existing U1 support.

## What's new

- Enable **Spoolman Location Sync** separately for each supported printer, then choose an existing **Spoolman Location** in printer settings. Synchronization is disabled by default for existing installations.
- PrintBuddy updates the location when a spool is assigned, replaced, moved, or unassigned through supported printer slots. A saved location remains usable when it has no spools and is absent from Spoolman's current location groups.
- The Snapmaker U1 chamber-light toggle now reads the physical state on startup and reconnection and follows external light changes. Existing light commands are preserved.

Snapmaker U1 functionality was tested with paxx12 Extended Firmware. Compatibility with unmodified stock firmware has not been established. Existing Bambu support remains available.
